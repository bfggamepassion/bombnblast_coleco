What's New in Version 2.0a

A small maintenance update focused on real ColecoVision hardware. Gameplay is unchanged from version 2.0.

Safer on real consoles

  • The new smooth display engine now leaves the video chip more time between writes, so graphics updates stay reliable on a real TMS9918A video chip. Emulators don't enforce this limit, so the problem was invisible there.
  • Fixed a rare issue, present since the original release, where loading the graphics on the menu screen could be interrupted by the video chip at a bad moment and scramble part of the video memory.
  • More free memory for the system stack, for extra safety margin.

Ready for flash carts and EPROMs

The ROM file is now padded to exactly 32 KB, the size most EPROM programmers and flash cartridges expect.

Free game

Version 2.0a of the game is free. No permission has been given to sell it as a physical release.
