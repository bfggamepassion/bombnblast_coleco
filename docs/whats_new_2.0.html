What's New in Version 2.0

Fifteen years after its release, Bomb'n Blast gets its biggest update yet: everything on screen now moves smoothly.

Smooth falling pieces

Pieces no longer jump down one block at a time. They now glide down pixel by pixel, at the same speed as before. Soft drop is smooth too.

Smooth sideways movement

Moving a piece left or right now makes it slide across instead of snapping to the next column. The slide takes just a few frames, so the controls stay as quick as ever.

More responsive controls

In earlier versions, every move and rotation redrew the whole screen. Now only the piece is updated, so moves and rotations show up right away.

Same game you know

The rules, levels, fall speeds and scoring are unchanged. Only the display is new.

Title screen

The opening screen now shows MICHEL LOUVET, replacing the old Collector Vision logo. The copyright line is replaced by a notice that this version is free.

Free game

Version 2.0 of the game is free. No permission has been given to sell it as a physical release.

Under the hood

  • A new display engine written in Z80 assembly redraws the falling piece every frame. The ColecoVision only allows 2 colors per 8-pixel line, so while a piece slides sideways a few edge pixels change color for a moment, and the piece looks exactly right again once it stops.
  • Source code is available on GitHub.
